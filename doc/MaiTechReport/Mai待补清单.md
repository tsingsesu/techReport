## 三、实测数据

请尽量提供日志或现场记录，没有的写“未测”即可，不要编。

| 项目 | 需要的数据 |
|---|---|
| 直线测试 | 能否全程不碰挡板；跑偏情况 |
| 非接触发车 | 挥手到发车的大致时间；有无误触发 |
| 锥桶绕行 | 两组是否一组变道、二组回线；碰锥次数 |
| 菱形减速 | 是否识别；减速是否明显；刹车灯是否亮 |
| 横道停车 | 是否停在停车线前；是否压线；停车是否满 5 s |
| 完整流程 | 单轮用时；主要扣分项 |

## 六、图片插入方法

把照片放进 `MaiFigs/`，例如 `Mai整车.jpg`，然后把对应的

```latex
\MaiPhotoPlaceholder{6cm}{【待插入：整车机械结构照片】}
```

替换成

```latex
\includegraphics[width=0.82\textwidth]{MaiFigs/Mai整车.jpg}
```
